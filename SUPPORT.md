# Support

## How to get help

| Need | Where |
|------|--------|
| Bug in the app | [Bug report](https://github.com/muhamm-ad/TilawatyApp/issues/new?template=bug_report.yml) |
| Feature idea | [Feature request](https://github.com/muhamm-ad/TilawatyApp/issues/new?template=feature_request.yml) |
| Quran text / translation mistake | [Translation / content report](https://github.com/muhamm-ad/TilawatyApp/issues/new?template=translation_or_content.yml) |
| Question or discussion | [Discussions](https://github.com/muhamm-ad/TilawatyApp/discussions) |
| Security vulnerability | [Private advisory](https://github.com/muhamm-ad/TilawatyApp/security/advisories/new) — see [SECURITY.md](SECURITY.md) |

## App information

- **Name:** Tilawaty
- **Website:** https://tilawaty-iota.vercel.app
- **Platforms:** Android, iOS, web
- **Languages:** English, French
- **Privacy:** No account; data stays on your device

Store listing links and a public support email are not published yet. Until then, use the channels above.

## Response expectations

This project is maintained by a single volunteer maintainer. Triage may take time. Please keep one issue per topic and reply to `needs-info` requests when asked.
