# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | Yes       |

Older versions are not supported with security updates.

## Reporting a vulnerability

**Do not open a public issue** for security vulnerabilities.

Please report them privately using [GitHub private vulnerability reporting](https://github.com/muhamm-ad/Tilawaty-Issues/security/advisories/new) on this repository.

Include:

- A clear description of the issue
- Steps to reproduce (if applicable)
- Affected platform(s) and app version
- Potential impact

You should receive an acknowledgment within a few days. We will keep you informed of the status while we investigate and, if needed, prepare a fix.

Tilawaty stores all data on the device and does not use accounts or analytics. Still, treat any data that could identify a person as sensitive.

## Preferred channel

GitHub Security Advisories for `muhamm-ad/Tilawaty-Issues` (no public contact email is defined yet).
